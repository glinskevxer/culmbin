regenerates it from the console script and fails if the two disagree.

## `culmbin standard`

The intake quality standards a purchase is bought against.

## `culmbin standard add NAME`

Write a quality standard.

| option | required | what it is for |
| --- | --- | --- |
| `--moisture-base` |  | the moisture weight is settled at. |
| `--moisture-reject` |  | wetter than this and the load goes back. |
| `--nitrogen-min` |  | the bottom of the contract band, on dry matter. |
| `--nitrogen-max` |  | over this the deduction schedule starts. |
| `--nitrogen-reject` |  | over this there is no schedule and the load goes back. |
| `--screenings-free` |  | screenings allowed before any come off the weight. |
| `--screenings-reject` |  | over this the load goes back. |
| `--germination-floor` |  | under this the load goes back, whatever else it grades. |
| `--energy-floor` |  | the germinative energy new crop has to reach. |

## `culmbin standard copy NAME INTO`

Start next season's standard off last season's thresholds.
